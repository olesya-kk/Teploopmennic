# HeatExchanger

**Проектный расчёт кожухотрубного теплообменника** на C++ и Qt Widgets.

Приложение подбирает геометрию аппарата по температурам, расходам и допустимым потерям давления. Каждый вариант проходит тепловой и гидравлический расчёт; результаты сохраняются в SQLite и доступны для загрузки и сравнения.

**Стек:** C++17 · Qt 6 Widgets / SQL / Concurrent · OpenMP · SQLite · CMake

## Возможности

- Прямоток, противоток и многопроходные схемы с подбором 1–3 ходов кожуха.
- Ручной ввод свойств или выбор из справочника: 30 сред, 464 температурные точки.
- Подбор по 176 стандартным сочетаниям геометрии с перебором перегородок и ходов.
- Расчёт Re, Pr, Nu, коэффициентов теплоотдачи, K, площади и потерь давления.
- Итерационное уточнение K; вывод числа итераций и достигнутой невязки.
- Параллельный перебор вариантов средствами OpenMP.
- История расчётов, восстановление исходных данных, сравнение вариантов и экспорт спецификации в TXT.
- Просмотр справочников и источников данных в интерфейсе.

## Быстрый запуск

### Ubuntu

Установите зависимости:

```bash
sudo apt install build-essential cmake qt6-base-dev libqt6sql6-sqlite
```

Из корня склонированного проекта выполните:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
./build/heat_exchanger
```

### Qt Creator

Откройте корневой `CMakeLists.txt`, выберите комплект **Desktop Qt 6 / GCC**, настройте проект и соберите его. Для запуска выберите цель **`heat_exchanger`**. Рекомендуемая конфигурация для измерения производительности — Release.

## Использование

1. Задайте температуры в °C, массовые расходы в кг/с и допустимые потери давления в **Па**. В форме уже заполнен проверочный пример.
2. Выберите свойства сред, материал стенки и загрязнения для каждого потока.
3. Укажите схему течения, минимальный запас площади, допуск K, предел итераций и число потоков OpenMP.
4. Нажмите **«Рассчитать»**. Программа выберет допустимый аппарат с минимальной наружной площадью поверхности.
5. Результат сохраняется автоматически. **«Сохранить…»** экспортирует спецификацию в TXT.
6. Для сравнения откройте **«История и сравнение расчётов»**. Выберите строку и нажмите **«Загрузить выбранный расчёт»**; двойной щелчок также поддерживается. После возврата назад в форме будут восстановленные исходные данные.

В режиме «Нагрев» поток 1 холодный, поток 2 горячий; в режиме «Охлаждение» — наоборот. Горячий поток размещается в трубах, холодный — в кожухе.

**Тепловой баланс:** отдаваемая горячим потоком и получаемая холодным потоком нагрузки должны согласовываться. При расхождении более 5% приложение показывает обе нагрузки и расчётный холодный расход при неизменных остальных параметрах. [Пример исправления](docs/TEST_CASES.md#3-несогласованный-баланс-и-его-исправление).

## Данные и SQLite

База создаётся и заполняется приложением. Отдельный сервер или редактор SQLite для запуска не требуется. Обычный путь в Linux:

```text
~/.local/share/StudyHeat/HeatExchanger/heat_exchanger.sqlite
```

Путь определяется `QStandardPaths::AppDataLocation` и учитывает `XDG_DATA_HOME`. Время истории хранится в UTC. Обновление справочников выполняется транзакционно с сохранением истории; исходные данные и результаты прежних расчётов не перезаписываются.

Справочники встроены в приложение из [`data/pakht.json`](data/pakht.json). Источник — «ПАХТ. Дидактический материал к практическим занятиям»: свойства воды — с.109–111, органических жидкостей — с.123–124 и 127–128, загрязнения — с.136, типоразмеры — с.137. Происхождение данных и SHA-256 исходного PDF сохранены в каталоге. Условия справочных значений материалов указаны в [отчёте](docs/REPORT.md#перенос-таблиц-и-исправления).

Исходный PDF не нужен для сборки и запуска и не включён в состав публикации. Для повторного извлечения таблиц поместите его в корень под именем `PAKhT_Didakticheskiy_material_k_prakticheskim_zanyatiam.pdf` и выполните `python3 tools/import_pakht.py`. Для этого дополнительно нужны Python 3 и `pdftotext` из пакета `poppler-utils`.

## Расчётная модель

Рассматривается однофазный теплообмен без фазовых переходов. Объёмные свойства определяются при средней температуре потока; свойства у стенки уточняются итерациями. K отнесён к наружной цилиндрической площади. Экстраполяция справочных свойств запрещена.

Теплоотдача рассчитывается по корреляциям ПАХТ; в переходном трубном режиме используется интерполяция. Гидравлика труб — Дарси–Вейсбах с местными сопротивлениями, кожуха — оценка типа Kern. Определение сечений перегородок приближённое. Патрубки, утечки пучка, вибрация и прочностной расчёт не включены. Полные формулы и допущения приведены в [отчёте](docs/REPORT.md#методика-расчёта).
